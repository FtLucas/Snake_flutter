# Comment télécharger le son de crunch de pomme depuis Freesound

## Le son recommandé par l'utilisateur :
https://freesound.org/people/LilMati/sounds/348112

## Instructions de téléchargement manuel :

1. **Ouvrez le lien** dans votre navigateur : https://freesound.org/people/LilMati/sounds/348112

2. **Cliquez sur "Download"** (bouton de téléchargement)
   - Si demandé, créez un compte gratuit Freesound (5 minutes)
   - OU connectez-vous si vous avez déjà un compte

3. **Le fichier sera téléchargé** (probablement dans votre dossier Téléchargements)

4. **Renommez le fichier** en `eat.mp3` (s'il a un autre nom)

5. **Déplacez le fichier** dans le dossier :
   ```
   D:\pour le travaille\creation jeux\snake_game\assets\sounds\eat.mp3
   ```
   (Remplacez le fichier existant si demandé)

6. **Relancez l'application** :
   ```
   flutter run
   ```

## Alternative rapide (si vous n'avez pas de compte Freesound) :

Je peux chercher un autre son de crunch de pomme sur Mixkit ou une autre source qui ne nécessite pas d'authentification. Dites-moi si vous préférez cette option !

## Vérification

Une fois le fichier remplacé, testez en jouant une partie et en mangeant une pomme.
Vous devriez entendre le nouveau son ! 🍎🔊
